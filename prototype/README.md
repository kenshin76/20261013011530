# PAGEWAY 교육 — 교과서·참고서·단행본 통합 사이트 체험판

위시켓 158957 과업(교과서·참고서·단행본 사이트 통합, Spring Boot 재구축)의 주요 화면과 관리 기능을 가상 자료로 체험하는 정적 HTML·CSS·JavaScript 사이트입니다. `index.html`과 `assets` 폴더를 그대로 GitHub Pages에 올리면 동작합니다.

## 체험 경로

| 화면 | 주소 | 확인할 수 있는 기능 |
| --- | --- | --- |
| 홈 | `index.html` | 통합 검색창, 새 책·시리즈·수업 자료, 독서 교육 제안; 도서관·독서 모임 사진과 배너 |
| 통합 검색 | `#/search?q=문학` | 도서명·작가·시리즈 동시 검색, 「교과서·참고서 / 단행본」 탭별 건수, GET 주소 복사·공유, 뒤로가기 경고 없음 |
| 도서 상세 | `#/books/6` | 작가(역할), 카테고리 다중 분류(★ 대표), 연결된 수업 자료 내려받기, 관련 독서 교육 제안 |
| 독서 교육 제안 | `#/reading` | 자료 중심 카드, 자료 하나에 여러 도서 연결, 목록 안 검색·주제·대상 필터(주소 공유 가능), 공통 대상 자료 별도 분류 |
| 자료실 | `#/resources` | 수업 자료와 게시판 유형(일반형·갤러리형·파일 다운로드 전용), 게시판별 목록 개수·페이지 이동 |
| 게시글 상세 | `#/resources/notice/1`, `#/resources/gallery/1` | 제목·본문·이미지 확인, 이전·다음 글 이동, 해당 글이 있는 게시판 목록 페이지로 복귀 |
| 예전 주소 찾기 | `#/qr` | 예시 항목 클릭 → 옛 주소 연결 과정을 모의 재현 (같은 옛 ID 1203도 원본 사이트별로 다른 책에 연결); QR 그림은 실제 스캔용 코드가 아님 |
| 관리자 로그인 | `#/admin/login` | 체험계정 선택 → 이메일·비밀번호 자동 입력 → 로그인 버튼으로 진입 |
| 관리자 | `#/admin` | 로그인 후 아래 표의 관리 기능 이용. 로그인하지 않은 상태에서는 로그인 화면 표시 |

`index.html?u=<옛 주소>`로 열면 해당 옛 주소가 새 주소로 안내되는 과정을 바로 보여 줍니다.

### 관리자 체험 (`#/admin`)

사이트의 「관리자」를 누르면 사진과 로그인 양식, 체험계정 목록으로 구성된 로그인 화면이 열립니다. 체험계정을 선택하면 입력칸에 채워지며, 「로그인」을 눌러야 관리 화면으로 이동합니다.

| 체험계정 | 이메일 | 비밀번호 |
| --- | --- | --- |
| 운영 관리자 | `admin@demo.pageway` | `pageway2026` |
| 콘텐츠 담당 | `editor@demo.pageway` | `editor2026` |

두 계정은 같은 관리 기능을 제공합니다. 실제 서버 인증이나 직무별 권한 분리를 구현한 것은 아닙니다. 관리자 왼쪽 아래에서 로그아웃할 수 있고, 로그아웃해도 수정한 체험 자료는 유지됩니다. 체험계정과 데이터 초기화는 로그인 양식 아래의 같은 카드에 모았습니다. 초기화는 로그인 전에도 이용할 수 있습니다.

도서·자료 편집 팝업은 첫 입력 항목에 포커스를 두고, Tab·Shift+Tab 이동을 팝업 안으로 제한합니다. ESC·취소·배경 클릭으로 닫으면 미저장 내용은 반영하지 않고 원래 버튼으로 돌아갑니다. 저장 후에도 새로 표시된 편집·등록 버튼으로 포커스를 돌려줍니다. 한글 조합 중 ESC는 팝업 닫기로 처리하지 않습니다.

| 메뉴 | 기능 |
| --- | --- |
| 대시보드 | 콘텐츠 현황, 자료·도서 관리 바로가기, 확인이 필요한 옛 주소, 파일 확인 필요 자료, 최근 작업 |
| 도서 | 도서-작가 N:M(역할·표시 순서), 도서-카테고리 N:M(대표 1개), 연결 자료 지정 — 저장 즉시 사이트에 반영 |
| 작가 마스터 | 작가 CSV 분석 → 출생연도 형식 확인 → 띄어쓰기·출생연도로 중복 후보 표시 → 병합 또는 새로 등록. 출생연도는 네 자리 숫자 또는 빈 값 |
| 자료 · 노출 순서 | 자료 독립 등록, 여러 도서 연결, 메인/자료실 노출 켜기·끄기, 상단 고정과 순서(끌기 또는 ↑↓) |
| 게시판 | 유형을 골라 새 게시판 생성 → 자료실에 바로 표시. 지정한 목록 개수에 따라 일반형·갤러리형·파일형 모두 페이지 분리 |
| 옛 주소 · 301 | 주소 시험기(처리 단계 표시), 전수 검증(DB의 모든 옛 ID + 대소문자·https 변형 + 접속 로그), 예외 매핑표(301/410), 원본별 ID 대응표, 매핑 실패 기록 |
| 운영 요청 | 이번 달·다음 달 요청 분리, 상태·순위 관리, 초과분 선사용(누적 최대 4 MD)·추가 정산·차월 이동, 다음 달 할당 차감 |

## 체험 환경 안내

- 브랜드·도서·인물·자료·도메인(`example.co.kr`)은 모두 가상입니다.
- 관리자에서 바꾼 내용과 로그인 상태는 브라우저의 localStorage에 저장되어 새로고침 후에도 유지됩니다. 로그인 상태에는 계정 이메일만 저장하며 비밀번호는 저장하지 않습니다. 로그인 화면의 체험계정 아래에 있는 「체험 데이터 초기화」로 자료를 처음 상태로 되돌릴 수 있습니다. 로그인하지 않아도 이용 가능하며, 초기화하면 로그인 상태와 관리 화면의 임시 입력도 해제됩니다. 관리자 화면에는 초기화 버튼을 두지 않습니다. 저장소가 차단된 환경에서는 현재 창에서만 유지됩니다.
- 저장 자료가 불완전하면 유효한 자료를 유지하고 확인이 어려운 부분을 초기 자료로 복구합니다. 원본은 `pageway-proto-v1-recovery-backup` 키에 보관합니다. 백업 저장이 실패하면 기존 원본을 덮어쓰지 않고 현재 화면에서만 작업하도록 안내합니다. 체험 데이터 초기화 시 복구 백업도 제거됩니다.
- 이전 버전에서 ‘다음 달 이동’이나 한도를 초과한 선사용으로 저장한 대기 요청은 차월 목록으로 보존합니다. 기존 게시글에 본문이 없으면 새 체험용 본문을 표시합니다.
- 내려받기는 체험용 안내만 표시하며 실제 파일을 내려받지 않습니다. 「중학 국어 1-2 맛보기 단원」은 파일 누락 상황을 보여 주는 예시이며, 관리자 대시보드의 「파일 다시 연결」로 정상화할 수 있습니다.
- 301 처리는 실제 서버가 아닌 브라우저에서 같은 규칙을 재현한 것입니다. 실제 서비스에서는 ALB가 옛 도메인 요청을 애플리케이션으로 넘기고, 애플리케이션의 레거시 호환 계층이 301 응답을 보냅니다.
- 검색·필터는 해시 주소(`#`)에 조건을 저장합니다. 뒤로가기·주소 공유 흐름의 데모이며 실제 Spring Boot 서버의 GET 응답이나 검색 성능을 검증한 것은 아닙니다.
- 「본문 바로가기」는 현재 화면 주소를 유지한 채 본문으로 포커스를 옮깁니다. 옛 주소 안내는 주소 형식·등록 도메인 오류, 연결 대상 미확인, 제공 종료를 구분합니다. 미확인 연결 대상만 확인 요청으로 기록합니다.
- 관리자 로그인은 브라우저 안에서 체험계정 정보를 비교하는 데모입니다. 코드와 저장소를 열어볼 수 있는 정적 사이트이므로 실제 서버 인증·운영 보안 기능을 대신하지 않습니다.
- 사진 6종은 AI 생성 이미지입니다. 이번에 추가한 3종에는 성인 독자·편집자·교사가 등장합니다. 실제 시설·인물·수업 사례의 사진이 아닙니다. 생성 프롬프트와 파일은 `IMAGE_PROMPTS.md`에 기록했습니다. JPEG 6종의 합계는 약 1,007 KiB입니다. 기존 도서관 사진 원본은 보관하고 홈 배경은 새 사진으로 교체했습니다.
- 글꼴(Pretendard)은 jsDelivr CDN에서 불러옵니다. 연결되지 않으면 시스템 글꼴로 표시됩니다.

## 검토·검사

`node tests/verify.cjs`로 화면 생성과 기능 로직을 재검사할 수 있습니다. 2026-10-13 재검사에서 93항목 모두 통과했고, 96개 화면 경로·편집창 2종·추가 경계 사례 13개의 HTML 총 111종을 확인했습니다. 최소 DOM 대체 객체를 사용하는 소스 수준 검사이며 실제 브라우저 클릭·반응형 화면·실제 키보드 조작 검사를 대신하지 않습니다. 실패 시 종료 코드 1이 반환됩니다. 자세한 결과는 `REVIEW.md`를 참고하세요.
